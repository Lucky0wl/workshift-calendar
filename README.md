# Календарь рабочих смен (Android)

Простое Android‑приложение на Jetpack Compose для планирования рабочих смен с готовыми шаблонами и несколькими визуальными стилями.

## Возможности

- **Календарь**: помесячный календарь с подсветкой смен и текущей даты.
- **Типы смен**: утро, вечер, ночь и выходной, у каждого свой цвет.
- **Шаблоны графиков**: готовые схемы (например, 2 дня / 2 ночи / 4 выходных, 5/2 и т.п.), которые можно применить ко всему месяцу.
- **Стили оформления**: несколько вариантов темы (современный синий, тёмный AMOLED, тёплый пастельный).

## Как запустить

1. Откройте папку проекта (`workshift`) в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на эмуляторе или реальном устройстве (мин. Android 7.0 / API 24).

## Структура

- `build.gradle`, `settings.gradle` — конфигурация Gradle.
- `app/build.gradle` — модуль приложения с зависимостями Jetpack Compose и Material 3.
- `app/src/main/AndroidManifest.xml` — манифест и главная активность.
- `MainActivity.kt` — основной UI: календарь смен, шаблоны и выбор стиля.
- `ui/theme/*` — оформление и преднастроенные стили приложения.
