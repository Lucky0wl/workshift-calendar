# Changelog

Все изменения в проекте "Календарь рабочих смен".

## [4.0.0] - 2025-03-05

### 🔒 Безопасность
- Удалены хардкод-пароли из build.gradle
- Настроены ProGuard правила для обфускации

### 🏗️ Архитектура
- Полная переработка архитектуры (Clean Architecture)
- Разделение на domain/data/ui слои
- ViewModel с StateFlow для управления состоянием
- Репозиторий для работы с данными

### 📦 Зависимости
- Kotlin 1.9.10 → 2.1.0
- Android Gradle Plugin 8.1.0 → 8.7.0
- Compose BOM 2023.08.00 → 2025.02.00
- targetSdk 34 → 35

### ✨ Новые функции
- Копирование смен на другой месяц
- Экспорт/импорт данных в JSON
- Статистика с круговой диаграммой
- Режим "Отпуск" с выделением в календаре
- Кастомные цвета для смен
- Валидация ввода (время, часы, зарплата)
- Уведомления на WorkManager
- Тёмная тема для стиля WARM_PASTEL

### 🧪 Тесты
- ShiftDetailsTest — расчёт часов смен
- ShiftKindTest — тесты enum смен
- VacationPeriodTest — периоды отпуска
- ExpenseMapperTest — мапперы расходов
- UtilsTest — утилиты форматирования

### 📱 UI
- Разбиение MainActivity на отдельные экраны
- CalendarScreen — календарь смен
- StatsScreen — статистика
- BudgetScreen — бюджет и расходы
- TemplatesScreen — шаблоны графиков
- SettingsScreen — настройки

### 🔧 CI/CD
- GitHub Actions для автоматической сборки
- Автоматическое создание релизов по тегам
- Артефакты APK после каждой сборки

## Формат

Проект следует [Semantic Versioning](https://semver.org/lang/ru/).

Формат changelog основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

### Типы изменений

- `Added` — для новых функций.
- `Changed` — для изменений в существующем функционале.
- `Deprecated` — для скорого удаления функций.
- `Removed` — для удалённого функционала.
- `Fixed` — для исправления багов.
- `Security` — для изменений безопасности.
